# Roadmap

This roadmap is intentionally short and public-facing.

## Current foundation

- Caddy-first `forward_auth` path
- trusted-header identity model
- basic login rate limiting
- admin-surface protection
- web console for events, rules, approvals, and settings
- early observability for response codes and latency

## Near-term priorities

- better deployment docs
- stronger Caddy log ingest and observability polish
- editable policy publishing workflow
- clearer production-ready configuration examples

## Mid-term priorities

- stronger AI-assisted suggestion flow
- better approval and audit workflow
- broader gateway support beyond the initial Caddy-first path

## Longer-term priorities

- enterprise collaboration controls
- multi-node sync
- richer policy distribution and management
