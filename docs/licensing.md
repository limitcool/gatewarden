# Licensing

Gatewarden uses a dual-track model:

- **OSS edition**: `AGPL-3.0-only`
- **Commercial edition**: separate proprietary agreement

## OSS edition

The public repository is intended for:

- self-hosted deployments
- local modification
- community contribution
- source-available security tooling

If you run a modified network-facing version, the AGPL requires you to provide corresponding source to network users.

## Commercial edition

A separate commercial agreement is the right path if you need:

- closed-source changes
- hosted closed-source SaaS use
- OEM or white-label rights
- proprietary integrations
- commercial support or SLA

See [../COMMERCIAL.md](../COMMERCIAL.md) for the short commercial overview.
